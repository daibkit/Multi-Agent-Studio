# Multi-Agent Studio

Ứng dụng web tương tác để mô hình hóa và mô phỏng hệ thống Multi-Agent AI (Claude + Gemini + Shared Memory).

- Single-file: mở `index.html` trực tiếp hoặc deploy tĩnh (Vercel, GitHub Pages).
- Kéo thả node, Inspector chỉnh cấu hình, 3 kịch bản mô phỏng, Export JSON / Mermaid.
